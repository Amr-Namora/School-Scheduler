Build the SchoolScheduler.Application project on top of the existing Domain
project. Use MediatR for CQRS and FluentValidation for input validation.

COMMANDS (write operations), each with a Command class, Handler, and Validator:
- CreateSchool, ConfigureWorkWeek (days/week, lecture times, break times)
- CreateGrade, CreateClassRoom
- CreateSubject
- CreateTeacher, AssignSubjectsToTeacher, SetTeacherAvailability
- CreateClassSubjectAssignment (class + subject + teacher + weekly quota)
- GenerateTimetable (School Id, or ClassRoom Id) — triggers the solver

QUERIES (read operations):
- GetClassTimetable(classRoomId) -> day x slot grid of subject+teacher
- GetTeacherTimetable(teacherId) -> day x slot grid of class+subject+school

- GetSchoolSetupStatus(schoolId) -> what onboarding steps are complete/missing

  impossible to satisfy").
- IApplicationDbContext or repository interfaces as needed for the handlers
  (keep persistence abstracted — no EF Core references in this project).
